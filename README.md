# daybük

A personal space to write — a free, no-signup journaling app. Everything you write is saved locally in your browser; there's no account and no server-side storage.

## Features

- **Home** — a running list of entries with search and mood/date filters.
- **Calendar** — a weekly view of your entries by date, with mood indicators.
- **Entry editor** — rich text formatting (bold, italic, underline, lists), mood and tags per entry, and freely draggable stickers.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Stack

Next.js (App Router) + React, styled with hand-written CSS and Tailwind utilities, Framer Motion for animation. Entries persist to `localStorage`.
